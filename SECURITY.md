# Security policy

Report security vulnerabilities through GitHub's private vulnerability reporting:

<https://github.com/carabistouflette/MedDataTrace/security/advisories/new>

Do not put credentials, patient records, restricted source material, withheld labels, or
other sensitive records in public issues, pull requests, discussions, or repository
comments. If private vulnerability reporting is unavailable, contact the repository
maintainers through a private GitHub channel rather than publishing sensitive details.

This repository is a public research foundation. Its public-safe content boundary is
described in `README.md`; `.gitignore` does not provide confidentiality.
